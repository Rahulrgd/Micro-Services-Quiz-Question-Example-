# MicroQuiz Hub

MicroQuiz Hub is an application that explores microservices architecture by implementing quiz-related services. It consists of two microservices: "Question Services" and "Quiz Services."

## Features

- **Question Services:**
  - Handles question-related functionality.
  - Provides endpoints for creating, retrieving, and managing questions.

- **Quiz Services:**
  - Manages quizzes and their components.
  - Allows users to create, take, and review quizzes.

## Technologies Used

- Spring Boot
- Eureka (Service Registry)
- OpenFeign (Microservices Communication)
- Kafka (Event Streaming)
- Spring Security (Microservices Security)
- Aspect-Oriented Programming (AOP)

## Getting Started

1. Clone this repository.
2. Set up the required dependencies (Eureka, Kafka, etc.).
3. Run both microservices.
4. Access the APIs via the provided endpoints.
